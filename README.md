# Employee Management System

## 📌 Project Description
This project is a simple **Employee Management System** developed using **React JS**.
It allows users to add, view, edit, delete, search, filter, and sort employee records.
The project uses **localStorage** to store data, so no backend is required.

This project is created for **learning and academic submission** purposes.

---

## 🚀 Features
- Add employee details
- View employee list
- Edit employee information
- Delete employee records
- Search employees by name
- Sort employees (A–Z / Z–A)
- Employee dashboard
- Data stored using localStorage
- Responsive design using Bootstrap

---

## 🛠️ Technologies Used
- React JS
- Vite
- JavaScript (ES6)
- React Router DOM
- Bootstrap 5
- HTML & CSS
- Browser localStorage
